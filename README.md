# 🛒 Amazon Clone Project

A static frontend clone of the Amazon homepage, built with pure HTML and CSS. Replicates the visual layout and structure of Amazon's product browsing experience — including the navbar, hero banner, and product category cards.

## 🛠️ Tech Stack

- **HTML5** — Page structure and layout
- **CSS3** — Styling, flexbox layout, and hover effects

## ✨ Features

- Amazon-style navigation bar with logo, search bar, and cart icon
- Full-width hero banner section
- Product category cards grid — including:
  - Apparel (dresses, jeans, tops, jackets, knits, shoes)
  - Kitchen & Dining (grilling pans, grilling tools, kitchen essentials)
  - Home & Furniture (accent furniture, bedding, baskets, décor, wallpaper & paint)
  - Personal Care
  - Tech & Gaming
  - Jewellery
- Footer with multi-column links (Amazon-style)

## 🚀 Getting Started

No setup needed — just open `index.html` in any browser.

```bash
git clone https://github.com/pr23sa/Amazon-clone-project.git
cd Amazon-clone-project
# Open index.html in your browser
```

## 🎯 Purpose

Built as a frontend development exercise to practice HTML/CSS layout techniques, including flexbox, image handling, and replicating real-world UI design from scratch.
